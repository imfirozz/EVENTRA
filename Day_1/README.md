# EVENTRA

## Overview

EVENTRA is a modern event discovery and ticketing platform designed to help users find experiences worth remembering. It connects attendees with technical conferences, workshops, meetups, and diverse cultural events.

## Internship Task

Create a Simple Responsive Landing Page Using HTML & CSS.

## Features

- **Responsive Navigation**: Includes a mobile-friendly hamburger menu built cleanly with CSS.
- **Hero Section**: A strong value proposition and clear call-to-action buttons.
- **Featured Events**: Responsive grid displaying upcoming events with pricing, dates, and locations.
- **Event Categories**: Quick exploration links across diverse event types.
- **Features Section**: Core value propositions highlighted with elegant glassmorphic cards.
- **Closing CTA**: A final push to explore or host events.
- **Footer**: Organized site links, company information, and social connections.
- **Glassmorphism Visual Design**: A dark premium aesthetic with subtle blurs, restrained shadows, and gradients.
- **Accessible & Responsive**: Accessible focus states, high contrast, and fluid scaling from 1440px desktop down to 375px mobile screens.

## Technologies

- HTML5
- CSS3

## How to Run

1. Open the project folder (`Day_1/`) in **VS Code**.
2. Install the **Live Server** extension (if not already installed).
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. The landing page will automatically open in your default web browser.

## Responsive Design

The layout utilizes CSS Flexbox and Grid, seamlessly adapting to:

- **Desktop**: Optimal viewing at 1024px to 1440px.
- **Tablet**: Adjusts column counts and spacing smoothly at 768px.
- **Mobile**: Collapses to a readable, easily tappable single-column layout for screens 480px and below.
